# 2D Shop Demo - FairyGUI Integration

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Controls:  
•Keyboard/Mouse  
WASD / Arrow Keys and Joystick for movement  
Inventory button on top right  
H for adding money with cheat  
E to interact with NPC

Technologies:  
• Unity 6000.1.9f1 C#  
• FairyGUI Unity SDK  
• DoTween (3rd Party Plugin)  
• Happy Harvest (3rd Party)  
• MyHelperPack (Belongs To Me)
